# HearMe

## Description
HearMe is an Electron-based desktop application that continuously monitors your microphone input and provides audio alerts when specific predefined keywords are detected in real-time speech.

## Features
- Real-time microphone monitoring
- Customizable keyword detection
- Audio alert system when keywords are detected
- Cross-platform compatibility (Windows, macOS, Linux)

## Technical Stack
- Electron
- React
- Speech Recognition API

## Installation
```bash
# Clone the repository
git clone [repository-url]

# Navigate to project directory
cd HearMe

# Install dependencies
npm install

# Start the application
npm run dev
```

## Usage
1. Launch the application
2. Grant microphone permissions when prompted
3. Configure your keywords in the settings
4. The application will run in the background and alert you when specified keywords are detected
